Claude Max: What You're Actually Buying (and How to Squeeze It)

7 sections · about 5 min read · claude-lab/00-max-plan-facts-and-rules.md

Read this BEFORE you pay. Facts come from Anthropic's own pricing, support and legal pages, read on 2026-11-25 (full quotes are in 01-raw-research-how-people-use-claude.md, Part A).

The plan, in plain words
  • Max is $100/month, monthly only. You get 5x Pro's usage every 5 hours AND every week.
  • Ultra is $200/month, 10x Pro per week and no 5-hour limit (for verified accounts). Don't start here. Upgrade only once you KEEP hitting the Max weekly wall on work that earns.
  • Max includes Claude Code, Cowork, Claude in Chrome, scheduled tasks, Opus, Sonnet, Haiku, and Fable (Anthropic's top model) for up to half your weekly limit.
  • Max also gives you $100/month in API credits on the Claude Platform. This is the sleeper perk, more on it below.
  • Usage does NOT roll over. "You receive your full weekly allowance each cycle." So a lazy week is literally money burned.
The ONE rule that decides how you can make money with it

This is the part most YouTube "make money with Claude" videos skip (dramatic, I know, but it matters).

What's allowed with your Max login:

  • You, personally, using the unmodified Claude Code, Claude Desktop, Cowork and claude.ai. For anything, including client work. You do the work with Claude, you sell the RESULT. That's normal use.
  • A client signing in to the unmodified Claude Code with THEIR OWN subscription, even on a machine or server you set up for them. So you can sell "I'll set up Claude for you", as long as they log in with their own account.

What's NOT allowed:

  • Building an app or bot for OTHER people that runs on your Max login. Anthropic's words: they don't permit developers "to route requests through Free, Pro, Max, or Ultra plan credentials on behalf of their users."
  • Collecting or storing someone else's Claude login.
  • Modifying the Claude Code program itself.
  • Anything you build as a product for others, including on the Agent SDK, "should use API key authentication".
  • Anthropic blocked third-party tools like OpenClaw from using subscription logins in April 2026 and says it can enforce "without prior notice". So don't build your income on a hack that might get your account shut.

What this means for you, in one line: USE Max to do work and build things, but anything that runs 24/7 serving paying customers should run on an API key. And that's exactly where the $100/month API credit comes in. It's free money to run your products' first customers on, the legit way.

Where your usage goes (so you don't run out by Wednesday)
  • Long chats eat more. Every message re-reads the whole conversation. Start fresh sessions often (/clear) and keep a CLAUDE.md so Claude doesn't need the history.
  • Big files eat more. Point Claude at the exact file, not the whole folder.
  • Fable is capped at half your weekly limit and costs the most. Use it for the HARD thinking (planning a business, architecture, tricky bugs), then let Sonnet or Haiku do the grunt work. Switch with /model.
  • Subagents run in their own context, so they keep your main chat small. But 10 agents in parallel burn 10x as fast. Parallel is for when you're racing a deadline, not by default.
  • Your weekly reset time is fixed per account. Check it in Settings > Usage, and plan your heavy builds for the 2 days AFTER a reset, not the night before.
How to keep Max busy while you sleep (the actual "maximize" trick)

The people getting the most from Max aren't typing more. They're queuing work so Claude keeps going while they're away.

  • Routines (cloud): saved Claude Code jobs that run on Anthropic's servers on a schedule, even with your laptop OFF. Create at claude.ai/code/routines or with /schedule. Good for: daily lead lists, competitor checks, research digests, drafting tomorrow's content.
  • Cowork Dispatch: text your PC from your phone, it works on your desktop files and apps. Needs the PC awake with Claude Desktop open.
  • Channels: message a running Claude Code session from Telegram or Discord. Perfect for "start this task" from the bus.
  • /loop and local scheduled tasks: repeat a task inside a session every N minutes.
  • Overnight build ritual: before bed, write a clear spec in a markdown file ("build X, test it, write what you did to PROGRESS.md"), start Claude Code in auto mode, go to sleep, review in the morning. This alone can double what you get from the plan.
A weekly rhythm for someone with a day to spare
  • Day 1 to 2 after reset: big builds (new project, new client deliverable). Fable for planning, Sonnet for building.
  • Day 3 to 5: client work and content. Mostly Sonnet.
  • Day 6 to 7: research, learning, cleanup, writing skills you'll reuse. Haiku or Sonnet. If you still have usage left the day before reset, dump it into a long research or overnight build. Leftover usage is wasted usage.
Your setup (Windows + phone + maybe a $5 VPS)
  • Install on Windows (PowerShell, no admin): irm https://claude.ai/install.ps1 | iex. Install Git for Windows too, it's "recommended" so Claude Code gets its Bash tool.
  • Install the Claude Desktop app (for Cowork, Dispatch and computer use) and the Claude mobile app.
  • Your laptop doesn't need to be on 24/7 for most of this, because Routines run in Anthropic's cloud.
  • A $5 VPS only becomes worth it when you have something that must ALWAYS answer (a client bot, a Telegram assistant listening all day). And remember, that thing should run on an API key if it serves other people.
Is Max worth it for you right now? (honest take)
  • If you're going to use Claude Code at least 2 to 3 hours a day on things that can earn, yes. Pro at $20 runs out fast with Claude Code.
  • If you're not sure yet, start with Pro for a week, get the Windows setup and your first CLAUDE.md working, THEN upgrade. Upgrading mid-month is easy. Paying $100 to spend the first week fighting an install is not.
  • The $100 API credit only helps if you actually build something that uses the API. So build one small API-powered thing in month one, so that credit isn't wasted either.

Part A. The official facts (read from Anthropic's own pages)

Plans (from claude.com/pricing, read 2026-11-25)

  • Free: $0. Limited usage. Chat, web search, code execution, memory, Artifacts. No Claude Code, no Opus, no Fable.
  • Pro: $20/month billed monthly ($17/month on annual, $200 up front). "1x" usage every 5 hours and every week. Includes Claude Code, Claude Science, Projects, Claude in Chrome and Microsoft 365, "Hand off and schedule tasks", Opus, Sonnet, Haiku. Fable only through paid usage credits. No monthly API credits.
  • Max: $100/month (monthly only). "5x Pro usage" every 5 hours and every week. Everything in Pro, plus "Fable included, up to half your weekly limit", "$100 a month in API credits to build on the Claude Platform", early access to advanced features, priority access at high traffic times.
  • Ultra: $200/month. "No 5-hour limit for verified accounts" and "10x Pro usage every week". Everything in Max, plus "$200 a month in API credits, up from $100 on Max". Fable up to 50% of weekly limits.
  • Footnotes on the page: "Price and plans are subject to change at Anthropic's discretion." and "How fast you reach a limit depends on the model you use, how long your chats are, and how large your files are."
  • Some third-party blogs still say "Max 5x" ($100) and "Max 20x" ($200). One says the old Max 20x was renamed Ultra and existing subscribers moved over with no price change. Trust the official page over those blogs.

How Max limits work (support.claude.com "What is the Max plan?", updated ~3 weeks before 2026-11-25)

  • "Max plans have a five-hour limit, a weekly usage limit that applies across all models, and a separate weekly limit for Fable."
  • "The weekly limit resets at a fixed time each week that is assigned to your account." You can see the next reset in Settings > Usage.
  • "you receive your full weekly allowance each cycle" (unused usage does NOT roll over, so an idle week is wasted money).
  • "If you have a limit reset, you can use it to reset your five-hour session limit or weekly usage limits back to full."
  • "Additional usage limits may apply to manage capacity and ensure fair access to all users." and "We don't guarantee uninterrupted service."
  • Monthly API credits come with Max, Ultra and Team.
  • Cowork is described as "Hand Claude work like reports, spreadsheets, and presentations, and it keeps going in the background."

The rules on subscription logins (code.claude.com/docs/en/legal-and-compliance)

This part matters a LOT for making money, so it's quoted word for word:

  • "OAuth authentication is intended exclusively for purchasers of Claude" Free, Pro, Max, Ultra, Team and Enterprise plans, and is "designed to support ordinary use of Claude Code and other native Anthropic applications."
  • "Developers building products or services that interact with Claude's capabilities, including those using the Agent SDK, should use API key authentication through Claude Console or a supported cloud provider."
  • "Anthropic does not permit third-party developers to offer Claude.ai login into their own applications, or to route requests through Free, Pro, Max, or Ultra plan credentials on behalf of their users."
  • "developers may not collect, store, or intermediate Claude.ai credentials or session tokens" (sign-in must "complete through Anthropic's own flow").
  • It does NOT prevent "an end user from signing in to the unmodified Claude Code binary with their own Claude subscription, including where a platform hosts Claude Code".
  • "The Claude Code binary must not be modified."
  • "Advertised usage limits for Pro, Max, and Ultra plans assume ordinary, individual usage of Claude Code and the Agent SDK."
  • "Anthropic reserves the right to take measures to enforce these restrictions and may do so without prior notice."

The OpenClaw "ban" story (news, Feb to Jun 2026)

  • Several outlets (MindStudio, The Next Web, DEV Community, Medium) reported Anthropic updated its terms on February 20, 2026 to forbid subscription OAuth tokens in third-party tools, then started blocking them on April 4, 2026 at 12:00 PM PT. OpenClaw was the big name hit.
  • First-party apps kept working: Claude Code, Claude.ai, Claude Desktop.
  • Workaround offered: pay-as-you-go API keys. One source quoted Sonnet 4.6 API pricing at $3 per million input tokens and $15 per million output tokens.
  • One newer blog (BetterClaw) claimed the ban was reversed on May 13, 2026 and a planned "Agent SDK credit" was paused on June 15. I could NOT confirm this anywhere else, and that site wouldn't load from the cloud box. The official legal page above is what counts.
  • Sources: MindStudio, The Next Web, DEV Community, BetterClaw, Is OpenClaw allowed in Claude Code?

First-party features people build Jarvis setups on

  • Channels: research preview launched March 20, 2026. Telegram and Discord first, iMessage about a week later. You message a RUNNING Claude Code session on your machine from your phone. Setup is a plugin install, then start Claude Code with the channels flag. Every channel has a sender allowlist (only paired accounts can talk to it). Sources: DataCamp, claudefa.st, fast.io, aiforautomation
  • Remote Control: watch and steer a local session from elsewhere (claude remote-control).
  • Routines: saved Claude Code jobs that run on Anthropic's cloud, created at claude.ai/code/routines or with /schedule. They keep running when your PC is off. Source: fast.io scheduled tasks guide, claudefa.st scheduled tasks
  • Local scheduled tasks and /loop: run inside your local session, often paired with a channel so results land in Telegram.
  • Cowork Dispatch: message Claude from your phone and it works on your desktop with your files, connectors, plugins and apps. The desktop must stay awake with the Claude Desktop app open. Computer use (Claude clicking around apps with no API) is in research preview for Pro, Max and Ultra. Risky actions pause and ping your phone for approval. Examples Anthropic gives: check email every morning, pull metrics every week. Sources: Anthropic blog, support article, XDA, Cowork use cases, DataCamp Dispatch

Windows install (code.claude.com/docs/en/setup)

  • PowerShell, no Administrator needed: irm https://claude.ai/install.ps1 | iex
  • Git for Windows is listed as optional on native Windows but RECOMMENDED (it gives Claude Code the Bash tool). Without it, Claude Code uses a PowerShell tool.
  • If Claude Code can't find Git Bash, set the path in settings.json.
  • Older guides that call Git "required" are outdated.

Z1. Format Bible reports for faceless channel builders

What it is: someone wants to start a faceless channel. You pick a channel that's winning, pull its last 50 videos (titles, transcripts, pacing, thumbnails, upload times), and write a "format bible": hook formulas, script structure, video length, posting rhythm, rough RPM, how crowded the niche is.

Who pays: laid-off tech and corporate workers in the US, UK, CA. $150 to $400/month.

What you can lose: your CLIENT'S LinkedIn account (much worse than yours). The safer version is what job-apply-kit does: the agent prepares everything, a human clicks submit. Slower, but nobody gets banned.

Z1. Rank and Rent
  • How: build a local lead-gen site for a service in a city ("Emergency Plumber Tulsa"), rank it, forward calls to a real plumber, charge rent or per lead.
  • Pays: flat $500 to $2,000/month, $25 to $100 per qualified call, or 5 to 10% of closed jobs. Ranked sites sell for 24 to 40x monthly revenue.
  • 2026 reality: still works for urgent, phone-first local queries. Thin AI-spun sites are dead (AI Overviews, tougher local results). Organic CTR on AI Overview queries down about 38%. Months 3 to 6 typically $0 to $500/month.
  • Gray part: the site looks like a local business but is a lead broker. Fake addresses on Google Business Profiles = suspensions.
  • How to do it without getting nuked: real local detail, real photos (from your renter), a real partner, no fake GBP addresses, call tracking numbers.
  • Risk: Platform Med, Legal Low.
Z2. Parasite SEO
  • How: publish on high-authority domains (Medium, LinkedIn Pulse, Reddit, YouTube, niche forums) to rank fast, then send traffic to affiliate offers.
  • 2026 reality: Google's site reputation abuse policy (since March 2024). Spammy parasite page lifespan reportedly down from about 9 months to 6 to 8 weeks. Affiliate-heavy = high risk. Thought-leadership-style = low risk.
  • Safer remix: use these platforms as "outposts" for genuinely useful content that links to YOUR site/newsletter. Fewer, better posts.
  • Risk: Platform Med to High (content removed, account banned), Legal Low.
Z3. Expired Domain Plays
  • How: buy expired domains with existing backlinks/traffic (GoDaddy Auctions, NameJet, Sedo, Flippa) and (a) rebuild a site on the topic, (b) 301 redirect to your site, or (c) resell to the old owner or a competitor.
  • Cost: about $10 to $22/year per domain + auction price.
  • Gray part: Google treats using expired domains mainly to manipulate rankings as spam ("expired domain abuse"). Reselling to the previous owner is legal but can feel like a squeeze. Trademark names = cybersquatting lawsuits (UDRP).
  • Risk: Platform Med, Legal Low (High if trademarks involved).
Z4. Unclaimed Property / Asset Finding
  • How: states hold billions in unclaimed money (old paychecks, refunds, deposits, insurance). Public databases list owner names. You find the owners (often businesses), and they sign an agreement giving you a % for recovering it.
  • Fee caps (examples): Illinois 10% (license needed), California 10%, New York 15%, North Carolina 20% or $1,000 whichever is less for most property (yearly $100 registration, law changed July 2026), Nevada no heir finder registration, Wyoming via notarized limited POA.
  • Gray part: owners could claim it themselves for FREE. You're charging for finding + paperwork. Many states require registration, contract disclosures, and waiting periods (Virginia bars certain agreements within 36 months).
  • Business-focused version (less creepy, bigger amounts): scrape the state databases for BUSINESS names with large amounts, contact the business's accounts department.
  • Edge: Claude Code can automate searching all 50 state databases (they're public) and matching names. Compliance per state is the real work.
  • Risk: Platform n/a, Legal Med (must comply with each state's finder law).
Z5. Scraping Public Data for Lead Lists
  • How: scrape public business data (Google Maps, directories, state filings, permit data) and sell enriched lists or use them for outreach.
  • US: scraping publicly available data has been treated as broadly legal in court (hiQ v. LinkedIn line of cases), but violating a site's terms can still get you banned or sued for breach of contract. Never scrape behind a login without permission.
  • UK/EU: GDPR applies to personal data (including sole traders' names, emails). Need a lawful basis (legitimate interest assessment), opt-out handling.
  • Outreach: US CAN-SPAM (real sender address, unsubscribe link, no deceptive subject lines). UK PECR (corporate emails OK with opt-out; sole traders treated like individuals).
  • Risk: Platform Med (IP blocks, ToS), Legal Low (US) to Med (EU/UK).
Z6. AI Influencer / Fan Platform Accounts
  • How: AI-generated persona on Fanvue (explicitly allows AI creators), plus Instagram/TikTok/X for traffic.
  • Fanvue: 80/20 split, MUST disclose AI (watermark, caption or bio, AI tag), can't claim to be a real person in posts or chats, up to 15 linked AI accounts per verified ID, payouts held 7 to 28 days, penalties from warnings to earnings deductions to bans.
  • Where the money is: paid DMs (about 60% of earnings in first two months per a Fanvue guide), subscriptions only about 10%. So it's a CHAT business. That means labor or chat automation.
  • Gray part: the traffic side. Instagram/TikTok require AI labels and restrict adult-adjacent content. Undisclosed AI personas pretending to be real people = bans and possible consumer protection issues.
  • Hard line (legal, not moral): never use a real person's face or likeness without consent (deepfake laws in many US states, UK Online Safety Act, EU AI Act). That one ends in court.
  • Risk: Platform High, Legal Low if disclosed + no real likeness; High otherwise.

  • How: Whop campaigns from casinos/crypto projects often pay the most (Roobet $1.50/1k with $250k budget, MUTUUM $6/1k).
  • Gray part: some of these brands aren't licensed in some countries, and platforms (TikTok, YouTube) restrict gambling promotion. Your accounts can get restricted. Promoting unlicensed gambling to some jurisdictions is illegal for the operator, and platforms ban the promoter.
  • Practical: use separate accounts for these campaigns so your main clipping portfolio accounts stay clean.
  • Risk: Platform High, Legal Low to Med (depends on where viewers are).
Z8. Prediction Market Arbitrage, Sold as Signals
  • How: run open-source scanners (AlexM800/poly-kalshi-arb is scanner-only; Synpath has paper trading) to spot price gaps between Kalshi and Polymarket, sell the ALERTS via a paid Telegram/Discord ($19 to $49/month) instead of risking your own money.

  • Gray part: jurisdiction. Kalshi is US-regulated, Polymarket access varies by country. Selling "signals" can be regulated as investment advice in some places if you frame it that way. Frame as "data/alerts, not advice". Subscribers who can't legally trade one venue can't use cross-venue arb.

Z10. Ghostwriting / Done-For-You Posting as the Client

  • Rules that keep you out of trouble: real business address in footer, working unsubscribe, honor it within 10 business days (US), no fake "Re:" subject lines, don't buy random email lists.

Z14. AI UGC Ads with Avatars
  • How: AI avatars "talking about" a product, sold to brands as cheap ad variants.

  • Safe framing: "presenter" style ads (avatar as a spokesperson), labeled as AI, no fake "I've used this for 3 months and my skin cleared" claims.
  • Risk: Platform Med, Legal Med if you fake testimonials.

  • How: you live where costs are low and sell in USD/GBP/AUD at Western rates.
  • Gray part: some clients assume you're local. Not illegal. Just don't lie about location if asked directly, it destroys trust when discovered. "I work remotely with clients in the US, UK and Australia" is honest and works.
  • Practical: work in their time zone for calls, use a US/UK virtual number (Google Voice requires US; alternatives exist), invoice in their currency via Wise.

The formula
[A proven DEMAND signal] + [a cheap SUPPLY trick] + [an underserved AUDIENCE] = a new offer

Examples from this folder:

  • Demand: "AI receptionists resell at $400 to $800" + Supply: AI voice agents at $0.07/min + Audience: immigrant-owned businesses -> G7 Bilingual AI Receptionist.
  • Demand: "podcasters pay $700/month for clips" + Supply: Whisper + FFmpeg + Claude picks moments + Audience: churches -> G13 Church Clipping.
  • Demand: "SaaS needs marketing" + Supply: Remotion templates + Audience: changelog pages nobody reads -> G6 Changelog Videos.
The 7 remix moves
  1. Swap the AUDIENCE. Take a service that works for one industry and move it to an underserved one (dentists -> veterinarians -> funeral homes -> churches -> trade schools).
  2. Swap the LANGUAGE. Take a service that works in English and run it in Spanish, German, Portuguese, Tagalog (and sell it to diaspora businesses in the US/UK/AU).
  3. Swap the MODEL. Service -> product (skill pack), product -> service (done-for-you), one-time -> subscription, fee -> revenue share, retainer -> pay-per-result.
  4. Invert the TARGET. Everyone targets "no website" businesses, target "DEAD website" businesses. Everyone sells to creators, sell to creators' EDITORS.
  5. Stack TWO data sources. Permits + Google reviews. Filings + LinkedIn jobs. Reddit pains + Amazon reviews.
  6. Move UPSTREAM. Instead of clipping, become the person who runs clipping campaigns (G24). Instead of using a tool, sell the setup of the tool.
  7. Find the "boring tax". Any task a business does weekly, hates, and is easy to automate = a subscription.

What happened in the cloud session
  • Agent-Reach was cloned and installed with uv, and agent-reach setup succeeded (5/5 default channels prepared: GitHub, YouTube, Bilibili, V2EX, web).
  • But the cloud container's network policy blocked the sites it reads (YouTube, Reddit, the GitHub API, Exa, Jina). Every query returned "blocked by proxy".
  • So the research for this folder used the built-in web search instead. On your own computer none of those blocks exist.
Install on your machine (Mac / Linux)

Install uv first if you don't have it:

curl -LsSf https://astral.sh/uv/install.sh | sh

Then install Agent-Reach from GitHub (NOT from PyPI, the PyPI package with that name is a different project):

uv tool install https://github.com/Panniantong/Agent-Reach/releases/latest/download/agent-reach.zip

agent-reach setup

Windows: install uv with

powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

then run the same two commands.

If agent-reach isn't found after install:

uv tool update-shell

and open a new terminal.

Easiest way: just tell Claude Code on your machine "install Agent Reach: https://raw.githubusercontent.com/Panniantong/Agent-Reach/main/docs/install.md" and it does everything. Setup also installs a Claude Code skill so Claude knows how to use it.

# Money Maker Folder

Built 2026-11-25. Profile this was built for: non-coder (Claude Code does the building), under $50 starting budget, selling to US / UK / EU / AU / CA buyers (NOT Asian markets, because of weak exchange rates), needs cash fast.

The rule for this folder: other people's ideas are BUILDING BLOCKS, not the plan. Every idea in `06-hidden-gems.md` and `07-gray-zone.md` is a remix (two or three proven pieces snapped together into something nobody is selling yet, or that very few people are selling).

## Quick ranking (my honest picks for someone broke, non-coder, $50)

Speed to first dollar, fastest first:

1. Claude Code / Cowork setup gigs on Fiverr and Upwork (Fiverr reports "Claude Code" searches up 938% YoY). See `02`, idea S1.
2. Website rescue for businesses whose site is DEAD (not "no website", DEAD). See `06`, gem G1.
3. Whop clipping campaigns (paid per view, no client needed), then graduate to podcast clipping retainers. See `03`, V3 and V4.
4. AI training work (Mercor / DataAnnotation / Outlier) as a cash floor while the others ramp. See `04`.
5. New-business-filings lead lists (public records, recurring subscription). See `06`, gem G4.

Highest ceiling (slower):

- Changelog / product-update videos for small SaaS companies with Remotion (`06`, G6).
- Localized "twin channels" for mid-size English creators on revenue share (`06`, G8).
- Chinese-platform trend arbitrage reports using Agent-Reach's Xiaohongshu / Bilibili channels (`06`, G10).
- Niche Claude skill packs for one profession (`08`).

## Honesty notes

- Most income numbers on the web come from vendors selling a tool or a course. `01-research-raw-notes.md` flags which ones are verified and which ones aren't. Treat every "$10k/month" claim as marketing until proven.
- Surveys this year found most active AI side hustlers make under $500/month. The ones who make more run a SERVICE with real clients. That's why this folder leans service-first, product-second.

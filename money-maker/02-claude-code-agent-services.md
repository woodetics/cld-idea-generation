# Claude Code and Agent Services

Services where YOU sell the outcome and Claude Code / agents do most of the labor. As a non-coder, your job is: find the client, understand the problem, tell Claude Code what to build, test it, deliver it, and support it.

Format for every idea: what it is, who pays, pricing, how Claude Code does it, first steps, risks.

---

## S1. Claude Code / Cowork Setup-as-a-Service

- What: you install and configure Claude Code (or Claude Cowork / desktop app) for a small business or solo professional, write 3 to 5 custom skills for their real tasks, record a walkthrough video.
- Why now: Fiverr reports "Claude Code" searches up 938% YoY. Most searchers are non-technical. The terminal scares them. Anthropic's Claude Marketplace (Sept 2026) means more people want plugins/skills set up.
- Who pays: realtors, accountants, recruiters, coaches, e-commerce owners, small agencies, lawyers (document workflows), course creators.
- Pricing: $75 / $200 / $450 tiers (see `09`). Upsell monthly "skill maintenance" at $49 to $99/month.
- How Claude does it: Claude Code writes the SKILL.md files, helper scripts, folders. You use the `skill-creator` skill to make and test skills.
- Skills that sell (examples): "turn a voice memo into a client email in my style", "weekly report from my Google Sheet", "rewrite listing descriptions", "invoice chaser", "meeting notes to CRM", "proposal generator from a template".
- First steps: build 5 demo skills for yourself for a single niche (e.g., real estate agents). Record a 3-minute video. Post a Fiverr gig in that niche.
- Risk: buyers expecting you to be an engineer. Scope tightly, say clearly what's included.
- Remix later: every skill you build for a client (minus their private info) becomes a product in your niche skill pack (`08`).

## S2. "Demo-First" Upwork Automation Freelancing

- What: before you send a proposal, Claude Code builds a WORKING mini version of what the client asked for. You send a Loom/screen recording of it running.
- Built from: Upwork n8n/automation demand (519 n8n jobs on one day in Oct 2026; AI integration +178% YoY) + the fact that 99% of proposals are text.
- Why it wins: clients get 50 proposals, yours is the only one with the thing already working.
- Pricing: one-time builds $200 to $1,500. Retainers $1,000 to $3,000/month.
- Workflow: filter jobs (automation, scraping, chatbot, Zapier, n8n, Make, Google Sheets, Airtable) posted in last 2 hours, budget $300+, payment verified, US/UK/AU/CA client. Spend max 45 minutes building a demo. Send.
- Gray tip: Agent-Reach (on your own computer) or a simple RSS feed of Upwork searches can alert you to new jobs instantly. Speed is half the win.
- Risk: spending time on demos that don't convert. Cap at 3 demos/day, track conversion.

## S3. AI Receptionist + Missed-Call Text-Back Reseller

- What: you set up an AI phone receptionist and missed-call text-back for local service businesses.
- Numbers: agencies reportedly charge $400 to $800/client on platforms costing $100 to $200 in usage. Upfirst $24.95/month (30 calls). Retell from $0.07/min. GoHighLevel $97 to $497/month with native features.
- Who pays: plumbers, HVAC, roofers, dentists, med spas, salons, auto repair, law firms. Anyone who loses money on missed calls.
- Pricing: $297 setup + $197 to $497/month.
- How Claude does it: writes the call scripts, knowledge base, FAQ, booking rules, the n8n/Make glue to send texts, and a simple dashboard of calls caught.
- Twist (hidden gem): BILINGUAL receptionist for immigrant-owned US businesses (Spanish, Vietnamese, Korean, Chinese, Tagalog). Many owners struggle with English-only calls, and English-only customers struggle with them. A bilingual AI answering in both is a real differentiator. See `06` G7.
- Risk: needs a small budget for the platform before the client pays. Get the client's first payment, then subscribe.

## S4. Review Reply Desk

- What: an agent drafts replies to every Google/Yelp/Facebook review for a local business daily, in the owner's voice. Owner approves with one tap (or auto-post for 4 to 5 stars).
- Why: Google rewards active review responses. Owners never do it. Boring = no competition.
- Pricing: $49 to $149/month per location. Multi-location (franchise) deals are gold.
- How: Claude Code builds the scraper/notification flow + drafting prompt + approval via email/WhatsApp.
- Upsell: monthly "what customers complain about" report (also see G5 Competitor Review Gap report).

## S5. Done-For-You Internal Tools for Small Businesses

- What: "I'll replace your messy spreadsheet with a simple app." Inventory trackers, booking tools, quote calculators, client portals.
- Built from: vibe-coding micro-SaaS trend + local business service model.
- Pricing: $500 to $2,500 per tool + $50 to $150/month hosting & changes.
- How: Claude Code + Supabase/Firebase free tier + Vercel. Or a Google Sheets + Apps Script setup (zero hosting cost).
- Risk: scope creep. Fixed scope, fixed price, change requests billed.

## S6. AI Knowledge Base / "Ask My Business" Bot

- What: a chatbot trained on a business's docs, FAQs, policies, price lists. Embedded on their site or used internally by staff.
- Who: clinics, schools/tutoring centers, property managers, SaaS support teams, HR departments, franchises.
- Pricing: $500 to $1,500 setup + $99 to $299/month.
- Twist: for COACHES and course creators, a bot trained on their content that answers students 24/7 (reduces their DM load). They already sell to students, so the bot is an upsell they can charge for.

## S7. Shopify / E-commerce AI Specialist

- Upwork flags "Shopify AI specialists" as surging.
- Services: AI product descriptions in brand voice (bulk), SEO collection pages built on real product data, abandoned-cart flows, AI support bot for "where is my order", product photo backgrounds, size-guide generation.

## S8. Data Cleanup and Migration Sprints

- What: "Send me your ugly spreadsheet/CRM export, I'll clean, dedupe, standardize, and import it." Claude Code is extremely good at this.
- Why: boring, urgent, everyone has it, nobody wants to do it.
- Pricing: $150 to $750 per job, by row count/complexity.
- Where: Upwork, Fiverr, local business owner groups, bookkeepers (they have clients with messy data).

## S9. Automated Reporting for Agencies (White-Label)

- What: marketing agencies spend hours making monthly client reports. You build automated reports (Google Ads, Meta, GA4, Search Console into a Google Slides / PDF / dashboard with AI-written commentary).
- Sell to: small agencies (2 to 15 people) in US/UK/AU.
- Pricing: $300 to $800 setup per report template + $20 to $50 per client per month.
- Why it's good: one agency = many clients = recurring revenue. White-label means the agency puts their logo on it.

## S10. Claude Code Tutor / Coach for Non-Technical Founders

- What: 1:1 sessions teaching founders to build with Claude Code themselves. Async (Loom + written) or live.
- Built from: coaching model (you may already understand community/coaching work) + Claude Code demand spike.
- Pricing: $50 to $150/hour or $300 to $600 for a 4-week package.
- Edge: you learn alongside, and you're honest about being a builder-operator, not an engineer. Beginners trust someone just one step ahead.

## S11. MCP Server / Connector Builder

- What: businesses want Claude to talk to THEIR tool (a niche CRM, an industry database, an internal API). You (Claude Code) build the MCP server.
- Pricing: $500 to $3,000 per connector.

- Pricing: $300 to $1,000/month.

## Quick picks

Start this week: E3 Listing Swarm Audits. No client needed to make a sample, and it teaches subagents, which almost everything else needs.

Hidden gems: E4 Exit Brain (knowledge capture for businesses being sold), E6 UK Making Tax Digital record prep (a government deadline does the selling), E13 "Bring your ChatGPT brain" migration.

Highest ceiling: E2 Department by the Month (your AI office sold as a content department), E11 The Import Channel (Chinese AI tools for a Western audience, using Agent Reach).

## The 3 things to remember

1. Use your Max login to DO work and BUILD things. Anything that serves other people 24/7 runs on an API key (your Max plan includes $100/month of API credit for exactly that).
2. Usage doesn't roll over. Queue work (Routines, overnight builds) so Claude works while you sleep.
3. Agents are great at doing work and bad at judging it. You're the editor. Keep a human check on anything a client sees.
